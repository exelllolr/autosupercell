# План: Детальное логирование и диагностика

## Цель
Добавить подробные логи сетевых запросов, проверку iframe, фокуса окна и viewport для диагностики проблем на сервере.

## Проблемы для диагностики
1. Сетевые запросы - что загружается, какие ошибки
2. Iframe - переключение контекста, потеря фокуса
3. Viewport/разрешение - несоответствие размеров окна
4. Warnings браузера - CSP, CORS, mixed content

### Уровни логирования
- INFO: основные действия, успешные запросы
- WARNING: redirects, медленные запросы (>5s), viewport mismatch
- ERROR: failed requests, iframe errors, console errors
