# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

## [0.1.0] - 2026-02-16

### Добавлено
- Полная структура проекта AutoSupercell
- Браузерная автоматизация с Playwright
- AI-поиск товаров через GPT-4 Vision
- Обработка платежей через Google Pay
- Управление прокси с ротацией
- Интеграции с Plati, Kupikod, FunPay, Avito
- API endpoints для обработки заказов
- Webhook поддержка для Kupikod
- Система очередей на базе Redis + ARQ
- Prometheus метрики для мониторинга
- Docker конфигурация
- Базовые тесты
- Документация (README, SPECIFICATION)

### Технологии
- Python 3.11
- FastAPI
- Playwright
- OpenAI GPT-4 Vision
- Redis + ARQ
- Prometheus
- Docker
