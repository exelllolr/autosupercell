# Гайд: API-ключ Anthropic (Claude, в том числе Vision)

Пошаговая инструкция: регистрация, получение ключа и подключение к программе autosupercell.

---

## 1. Регистрация в Anthropic

1. Откройте **Console (платформу)** Anthropic:  
   **https://platform.claude.com**

2. Нажмите **Sign up** / **Log in** и зарегистрируйтесь:
   - через **email** (подтверждение письмом), или  
   - через **Google** / **SSO**, если доступно.

3. Подтвердите email (если регистрировались по почте) и войдите в аккаунт.

4. Для платного API нужно **добавить способ оплаты** в настройках биллинга (карта). Бесплатный тир тоже есть — лимиты смотрите в Console.

---

## 2. Создание API-ключа

1. Войдите на **https://platform.claude.com**

2. Откройте раздел с ключами:
   - в меню: **Account** / **Settings** → **API Keys**, или  
   - напрямую: **https://platform.claude.com/settings/keys**

3. Нажмите **Create Key** / **Generate key** / **Add key**.

4. (Если спрашивают) выберите **Workspace** или оставьте default.

5. Введите **имя ключа** (например: `autosupercell` или `vision`) — для себя, чтобы не путать ключи.

6. Подтвердите создание. Ключ покажется **один раз** в виде строки, обычно начинается с `sk-ant-...`.

7. **Сразу скопируйте ключ** и сохраните в надёжное место (менеджер паролей, секрет в репозитории и т.п.). Повторно его посмотреть будет нельзя, только создать новый.

---

## 3. Какой ключ подходит для Vision

- Один и тот же **API-ключ** используется для всех моделей Claude, в том числе с **Vision** (анализ изображений).
- Отдельного «ключа для vision» нет: выбирается **модель** в коде (например `claude-sonnet-4` или `claude-opus-4`), а ключ один.
- В проекте autosupercell провайдер Claude уже настроен на использование этого ключа; при выборе провайдера `claude` будет использоваться ваша vision-способная модель, если она указана в коде.

---

## 4. Передача ключа в программу (autosupercell)

Ключ передаётся через переменные окружения, чтобы не хранить его в коде.

### Вариант A: файл `.env` (рекомендуется)

1. В корне проекта откройте (или создайте) файл **`.env`**.

2. Найдите или добавьте строку:
   ```env
   ANTHROPIC_API_KEY=sk-ant-ваш-ключ-здесь
   ```

3. Подставьте свой ключ вместо `sk-ant-ваш-ключ-здесь` (без кавычек и пробелов).

4. Чтобы приложение использовало именно Claude, установите:
   ```env
   AI_PROVIDER=claude
   ```

5. Сохраните файл. **Не коммитьте `.env` в git** — он должен быть в `.gitignore`.

### Вариант B: переменная окружения в системе/терминале

**Windows (PowerShell, одна сессия):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-ваш-ключ"
$env:AI_PROVIDER="claude"
```

**Windows (cmd):**
```cmd
set ANTHROPIC_API_KEY=sk-ant-ваш-ключ
set AI_PROVIDER=claude
```

**Linux/macOS:**
```bash
export ANTHROPIC_API_KEY="sk-ant-ваш-ключ"
export AI_PROVIDER=claude
```

После этого запускайте приложение из этого же терминала.

---

## 5. Проверка

- Запустите приложение (например, API или скрипт, который использует AI).
- В логах или через endpoint проверки провайдера не должно быть ошибок вида «invalid API key» или «authentication failed».
- В коде конфиг читает ключ из `settings.ANTHROPIC_API_KEY` (см. `app/config.py`), который подхватывается из `.env` или переменных окружения.

---

## 6. Безопасность

- Не вставляйте ключ в код и не коммитьте его в репозиторий.
- Не передавайте ключ в URL и не логируйте его.
- Храните ключ в `.env` (файл в `.gitignore`) или в секретах CI/сервера.
- При утечке — отзовите ключ в **https://platform.claude.com/settings/keys** и создайте новый.
