# AI Vision Migration: OpenAI → Claude

## Обзор

Миграция AI Vision поиска товаров с OpenAI GPT-4o на Anthropic Claude 3.5 Sonnet для улучшения точности распознавания и снижения стоимости.

## Проблема

Текущая реализация использует OpenAI GPT-4o для поиска товаров на скриншотах, но:

1. **Точность:** Claude 3.5 Sonnet показывает лучшие результаты в Vision задачах
2. **Стоимость:** Claude дешевле для Vision API (~40% экономии)
3. **Надёжность:** Claude лучше следует JSON-форматированию в ответах
4. **Конфигурация:** Нужна правильная настройка через `.env` и документация

## Технические требования

### TR-1: Claude Provider Implementation
```python
class ClaudeProvider(BaseAIProvider):
    """
    Anthropic Claude 3.5 Sonnet провайдер для Vision.
    
    Модель: claude-3-5-sonnet-20241022
    Max tokens: 1024 (для JSON ответа)
    """
```

### TR-2: Конфигурация
```bash
# .env
AI_PROVIDER=claude  # openai | claude | gemini
ANTHROPIC_API_KEY=sk-ant-...
```

### TR-3: Промпт-инжиниринг для Claude
- Использовать system prompt для JSON форматирования
- Явно указывать структуру ответа
- Добавить примеры (few-shot) для лучшей точности

### TR-4: Обработка ошибок
- Timeout: 30 секунд
- Retry: 2 попытки с exponential backoff
- Fallback: OpenAI если Claude недоступен

## Нефункциональные требования

### NFR-1: Производительность
- Время ответа Claude: < 5 секунд (95 перцентиль)
- Размер изображения: max 5MB (сжатие если больше)

### NFR-2: Стоимость
- Claude: ~$3 per 1000 images (vs $5 OpenAI)
- Кэширование промптов для снижения стоимости

### NFR-3: Надёжность
- Availability: 99.5% (с fallback на OpenAI)
- Error rate: < 1%

## Ограничения

1. **API Limits:** Claude API имеет rate limits (50 req/min для tier 1)
2. **Image Size:** Max 5MB per image, рекомендуется 1920x1080
3. **Latency:** Claude может быть медленнее OpenAI на 10-20%

## Зависимости

- `anthropic` Python SDK >= 0.18.0
- Существующий `BaseAIProvider` интерфейс
- `ANTHROPIC_API_KEY` в `.env`
